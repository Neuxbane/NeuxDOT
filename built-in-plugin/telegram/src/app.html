Used when a tool call omits chat_id. Send /start to @userinfobot to find your numeric id; channels use @channelname or a -100... id.
Telegram only formats text when this is set. HTML and MarkdownV2 require escaping the characters Telegram reserves; plain text is the safe default.
Authority lives in Telegram, not here. This plugin does not restrict which actions the bot may take. What it can do is decided by the bot's own rights in each chat: promote it to administrator in a group or channel to let it moderate, and demote it to take that away. A call the bot is not allowed to make comes back as a Telegram error naming the missing right.
Live update stream: connect this plugin to the agent, then subscribe to extension://telegram/updates in the plugin panel. The plugin long-polls getUpdates and pushes each incoming message into the agent without a tool call.
