Create an application at the Discord Developer Portal (discord.com/developers/applications), open the Bot tab and use Reset Token, then paste the token here. Leave blank to inherit the server-wide DISCORD_BOT_TOKEN. The bot must have the Message Content privileged intent enabled and be invited with the bot + applications.commands scopes. Its Discord permissions decide everything it may then do: grant Administrator for full server management, or the individual permissions (Manage Channels, Manage Roles, Kick/Ban Members, Manage Messages, Moderate Members, Manage Webhooks…) for a narrower bot.

Authority lives in Discord, not here. This plugin does not restrict which actions the bot may take. What it can do is decided by the bot's own role, its server permissions and the channel overwrites in Discord — grant or revoke there. A call the bot is not allowed to make comes back as a 403 naming the missing permission.
Live message stream: connect this plugin to the agent, then subscribe to extension://discord/messages in the plugin panel. The plugin holds a Discord Gateway v10 WebSocket connection and pushes each incoming message into the agent without a tool call. Requires the Message Content intent; bot-authored messages are ignored to prevent loops.
